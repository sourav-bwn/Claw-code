🚀 Setup in 2 Minutes

📥 Step 1: Install Ollama

Go to ollama.com and click Download. Install it on your computer.

⌨️ Step 2: Open Terminal & Paste

Open your computer's terminal (Terminal app on Mac, CMD on Windows) and run:

ollama pull llama3.2
ollama serve

❓ FAQ

Is this really free?

Yes! Ollama runs AI models locally on YOUR computer. No API keys, no subscriptions, no limits!

Why do I need to install Ollama?

Ollama is the software that runs the AI on your computer. It's like a web browser - you install it once and use it forever.

What models can I use?

llama3.2 - Great for everything
codellama - Better for coding
mistral - Fast and lightweight
phi - Tiny model for old computers

It's not working!

Make sure Ollama is still running. Check your terminal - you should see "Ollama is running". If not, run ollama serve again.
